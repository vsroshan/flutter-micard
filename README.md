MiCard 👤

A personal profile card application built with Flutter and Dart.

This project demonstrates how Flutter widgets can be combined to create a clean, visually structured interface for displaying profile information.

📱 Overview

MiCard is a digital business card-style application that presents personal information in a compact mobile interface.

The project focuses on layout composition, typography, styling, and the organization of reusable interface elements.

✨ Features

* Profile card interface
* Structured presentation of personal information
* Customizable colors and typography
* Flutter-based layout components
* Clean, card-style UI design

🛠️ Tech Stack

* Framework: Flutter
* Language: Dart
* Concepts: Layout widgets, styling, and reusable UI components

📚 Key Learnings

* Building layouts with Flutter widgets
* Using Column, Row, and Container
* Applying padding, margins, and alignment
* Styling text and interface elements
* Structuring information in a visually clear format

🚀 Getting Started

Prerequisites

* Flutter SDK
* Dart SDK
* A configured emulator or physical device

Installation

1. Clone the repository:

git clone https://github.com/vsroshan/flutter-micard.git

2. Navigate into the project directory:

cd flutter-micard

3. Install dependencies:

flutter pub get

4. Run the application:

flutter run
